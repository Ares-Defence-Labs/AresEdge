## Document boundary detection

[![AresEdge live document tracking and capture countdown](https://raw.githubusercontent.com/Ares-Defence-Labs/AresEdge/main/media/scanning-demo.gif)](https://github.com/Ares-Defence-Labs/AresEdge/raw/refs/heads/main/media/scanning-demo.mp4)

[Watch the MP4](https://github.com/Ares-Defence-Labs/AresEdge/raw/refs/heads/main/media/scanning-demo.mp4)

The document outline and capture countdown are visible in the AresScan scanner.
This is the host app's complete scanning screen. For your own toolbar, use
AresEdgeEmbedded. For the SDK's minimal toolbar, use AresEdgeScreen.

The first AresEdge release provides scanning and cropped, perspective-corrected document output. AresScan+
has additional editing tools which are separate from this SDK release.

## Try and measure

Install [AresScan+](https://aresdefencelabs.com/ares-scan) to try the app, or run the

Use the [performance workbench](performance-testing.md) to benchmark camera
throughput and detector latency on your hardware.

text formatting in the app references are outside the current SDK feature set.
