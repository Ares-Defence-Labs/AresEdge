# Support and purchasing

Read [getting started](docs/getting-started.md), the [API reference](docs/api-reference.md)
and [troubleshooting](docs/platforms.md). This is the public documentation/example
repository, not the SDK implementation package.

Use GitHub Issues for bugs, integration questions and feature requests. Include
SDK/Flutter versions, platform/device, a minimal reproduction and redacted errors.
Do not upload licence keys, private signing material or customer documents.
Questions can use the Question issue template. GitHub Issues is not a guaranteed
support SLA; paid support commitments are governed by your purchase agreement.

Purchase and renew through [the AresEdge portal](https://aresdefencelabs.com/development-sdks?sdk=edge-detection&view=overview).
For account/billing or sensitive issues contact team@aresdefencelabs.com privately.
Security reports follow [SECURITY.md](SECURITY.md).
