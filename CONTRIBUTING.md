# Contributing

Documentation corrections and integration-guide improvements are welcome as pull
requests. Use Issues for integration questions and bugs in the proprietary SDK.
Do not submit SDK implementation, extracted models, licence tokens, keys or
private application code. Include only material you have permission to share.

Check Markdown links and verify snippets against the customer SDK. Runnable
examples ship in the SDK package; this repository contains documentation only.
Do not add application source, workflows, build tooling or generated files.

modify and distribute that contribution as part of this documentation
and its commercial SDK integration materials. You retain your own copyright;
