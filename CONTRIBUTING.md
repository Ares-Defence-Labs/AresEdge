# Contributing

Documentation corrections and minimal example improvements are welcome as pull
requests. Use Issues for integration questions and bugs in the proprietary SDK.
Do not submit SDK implementation, extracted models, licence tokens, keys or
private application code. Include only material you have permission to share.

Check Markdown links and build/analyze the example against a locally supplied
customer SDK. The package is not published to pub.dev yet. Avoid committing
pubspec_overrides.yaml, generated files or local signing settings.
